
# 📘 Assignment: Hangman Game

## 🎯 Objective

Build a word-guessing game in Python using strings, loops, conditionals, user input, and random selection.

## 📝 Tasks

### 🛠️ Build the Guessing Gameplay

#### Description
Create the main Hangman gameplay: choose a hidden word and let the player guess its letters.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list
- Accept letter guesses from the player
- Show guessed letters in their correct positions and use underscores for unrevealed letters (for example, `_ _ _`)
- Track and display the number of incorrect guesses remaining

### 🛠️ Handle Game Outcomes

#### Description
End the game when the player guesses the word or runs out of attempts, and tell them the result.

#### Requirements
Completed program should:

- End when the hidden word is fully guessed
- End when the player has no incorrect guesses remaining
- Display a win message when the player guesses the word
- Display a lose message when the player runs out of attempts
